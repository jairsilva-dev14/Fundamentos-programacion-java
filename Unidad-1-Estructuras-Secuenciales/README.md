# Unidad 1 - Estructuras Secuenciales

Ejercicios desarrollados durante la Unidad 1 del curso de Fundamentos de Programación.

## Temas abordados

- Variables
- Operadores
- Entrada y salida de datos
- Estructuras secuenciales

## Ejercicios desarrollados

- Cálculo de área y perímetro de una tapa de alcantarilla
- Cálculo de distancia recorrida por un objeto en movimiento
- Conversión de grados a radianes
- Cálculo de gasto de combustible en un viaje
- Promedio de notas
