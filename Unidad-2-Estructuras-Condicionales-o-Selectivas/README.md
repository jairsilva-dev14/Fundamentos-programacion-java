# Unidad 2 - Estructuras Condicionales o Selectivas

Ejercicios desarrollados durante la Unidad 2 del curso de Fundamentos de Programación.

## Temas abordados

- if
- if-else
- if anidados
- switch-case
- Operadores lógicos (&&, ||)

## Ejercicios desarrollados

- Índice de Masa Corporal (IMC)
- Simulador de Dados con Apuestas
- Clasificación de Triángulos
- El Grillo Termómetro
- Identificador de Caracteres
- Conversor de Divisas
- Descuentos Escalonados en Tienda

## Tecnologías utilizadas

- Java
- NetBeans
