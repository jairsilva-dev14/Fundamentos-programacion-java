# Unidad 4 - Modularidad y Arreglos

Ejercicios desarrollados durante la Unidad 4 del curso de Fundamentos de Programación.

## Temas abordados

* Modularidad y arreglos

## Ejercicios desarrollados

* Promedio de Notas con Arreglos
* Búsqueda de Nombres en Vectores
* Cálculo de Monto de Ventas de Productos
* Sistema Evaluativo Modular con Arreglos (Caso de Examen Final)

## Tecnologías utilizadas

* Java
* NetBeans
